# FlashLearn – Flashcard Learning App

**FlashLearn** is a simple and interactive flashcard learning application developed using **Flutter and Dart** as part of my **App Development Internship at CodeAlpha**.

The app helps users learn and revise information through question-and-answer flashcards. Users can navigate between cards, reveal answers, and manage their own flashcards by adding, editing, and deleting them.

## ✨ Features

- **View Flashcards:** Display questions and answers through interactive flashcards.
- **Show Answer:** Reveal the answer to the current question with a single tap.
- **Next Card:** Move to the next flashcard.
- **Previous Card:** Return to the previous flashcard.
- **Add Flashcards:** Create new flashcards with custom questions and answers.
- **Edit Flashcards:** Update existing questions and answers.
- **Delete Flashcards:** Remove flashcards that are no longer needed.
- **Local Data Storage:** Save flashcard data locally using SharedPreferences.
- **User-Friendly Interface:** Clean, simple, and easy-to-use design.
